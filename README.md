🧩 Sobre o projeto

O Problema das n-Rainhas é um desafio clássico da Inteligência Artificial que consiste em posicionar n rainhas em um tabuleiro de dimensão n × n, garantindo que nenhuma delas ataque outra.

Este projeto explora diferentes algoritmos de busca para encontrar soluções válidas, investigando suas estratégias, eficiência e limitações.

🎯 Objetivos

- Compreender o problema como um espaço de estados.
- Implementar diferentes estratégias de busca.
- Analisar o comportamento dos algoritmos.
- Comparar desempenho em tempo, memória e quantidade de estados explorados.

⚙️ Algoritmos estudados

Algoritmo| Estratégia
🔎 Greedy| Busca Gulosa
⭐ A*| Busca heurística
↩️ Backtracking| Tentativa e retrocesso
⚡ Bitmasks| Otimização com operações de bits

📊 Análise de desempenho

Os experimentos consideram:

- Tempo de execução;
- Estados gerados e explorados;
- Tamanho máximo da fronteira;
- Consumo de memória.

Os resultados são organizados em tabelas e gráficos para facilitar a comparação entre as abordagens.
